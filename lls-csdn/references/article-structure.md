# CSDN 文章结构

采用半固定结构。每个章节都必须回答读者的真实问题，不为凑字数保留空章节。

## 顶部发布信息

标题直接写成唯一 H1。其上使用 **HTML 注释** 保存发布辅助信息，避免粘贴到 CSDN 后显示：

```markdown
<!--
CSDN 摘要：100 至 150 字，直接说明文章价值。
CSDN 标签：5 至 8 个自然关键词
备选标题：四个未采用标题，用中文分号分隔
调研日期：YYYY年M月D日
事实边界：说明资料范围、静态调研和未运行验证。
-->

# 推荐标题
```

生成五个标题候选并选择一个正文标题。标题以技术名称或明确问题为主体，可加入适度结果、矛盾或用途钩子，但不制造恐慌和虚假热度。

## 必选结构

1. 封面图。
2. `## 🚀 30 秒看懂`：包含“一句话看懂”和“先说结论”。
3. 技术或项目解决的问题。
4. 核心机制或架构。先给直觉模型，再解释真实机制。
5. 局限和风险。说明适用边界及未验证事项。
6. 总结与下一步：3 至 5 条简短结论、一个可行动的下一步、一个具体讨论问题；可自然提醒收藏，禁止模板化营销话术。
7. `## 参考资料`，下设 `### 官方资料` 和 `### 补充资料`。

## 可选结构

按主题选择：

- 为什么近期受到关注；
- 技术名词小词典；
- 常见误解；
- 使用场景；
- 同类工具对比；
- 官方最小代码示例；
- 如何开始了解或尝试。

不强制“适合谁 / 不适合谁”。同一信息不要在摘要、正文和总结中重复三次。

## 图片与 Mermaid

正文引用 PNG。架构图后紧跟 Mermaid 源码 HTML 注释，以便单 Markdown 保存可编辑源：

```markdown
![核心架构图](https://...)

<!-- Mermaid 源码：
graph LR
    A["输入"] --> B["处理"] --> C["输出"]
-->
```

上传失败时允许使用本地相对路径，但必须加入 `<!-- 图片待上传：文件名 -->`，不能假装链接已经可用。

## SEO 约束

- 核心关键词自然出现在标题、开头和信息充分的小标题中。
- 摘要和标签帮助发布，不写进正文段落。
- 可加入读者会真实搜索的问题，但禁止关键词堆叠。
- 动态事实使用绝对日期，不使用含糊的“最近、目前、现在”。
