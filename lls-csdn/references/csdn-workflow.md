# CSDN 交付工作流

## 本地文件

最终文章保存在：

```text
E:\雷大帅的博客文章\YYYY-MM-DD-安全化文章标题.md
```

删除 Windows 文件名中的 `< > : " / \\ | ? *`，去除结尾空格和句点。用户明确指定其他位置时，以用户位置为准。最终主要交付物只有一份 Markdown，过程图片保留在 `.lls-csdn-work/<slug>/`。

## 已授权操作

这个个人 Skill 已获持续授权：当**现有登录会话**可用时，可以打开 CSDN 编辑器、上传原创图片、取得图片 URL、替换 Markdown 链接，并把全文放入**草稿箱**。这些操作无需逐次确认。

授权不包含：

- 索取、读取、保存或传输账户密码；
- 点击发布或定时发布；
- 修改已发布文章；
- 删除远程图片、草稿或文章；
- 更改账户、专栏或隐私设置。

**绝不发布。** 即使用户过去授权过上传和草稿填充，也不能把它解释成发布授权。

## 上传顺序

1. 完成本地 Markdown 和图片，先运行文章校验器。
2. 使用已登录浏览器打开新的 CSDN Markdown 编辑页，不复用已发布文章编辑页。
3. 上传原创封面和架构图，等待每张图片出现可访问的 CSDN URL。
4. 替换对应本地链接，回查 Markdown 中没有误换其他 URL。
5. 将完整文章放入草稿编辑器，允许平台自身的自动保存。
6. 检查标题、图片、代码块、表格和参考资料预览。
7. 停在草稿状态，不点击发布按钮。
8. 把包含最终 URL 的 Markdown 再次保存到本地文章目录。

页面结构可能变化，应按可见标签和语义操作，不保存脆弱的坐标或选择器。

## 上传失败降级

未登录、页面不可用或上传失败时：

1. 官方图片继续使用可访问的官方远程 URL；
2. 原创图片保存在 `.lls-csdn-work/<slug>/`；
3. Markdown 使用相对路径，并紧邻加入 `<!-- 图片待上传：文件名 -->`；
4. 继续完成本地文章；
5. 最终只提醒一次哪些图片未上传，不反复要求用户登录。

不得把本地路径、上传请求成功或编辑器中出现预览误报为“CSDN 图片 URL 已完成”。
